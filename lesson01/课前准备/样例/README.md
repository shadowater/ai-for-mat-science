# 第一课课前检查样例

[返回课前准备](../README.md)

本目录提供可独立使用的虚构样品 `M-02`。Excel 与 CSV 保存同一张两列表格，供初学者对照；JSON 刻意写成单行，供练习 VS Code 的“格式化文档”。请将文件放在同一个文件夹中。

| 文件 | 内容与检查点 |
| --- | --- |
| [sample.xlsx](sample.xlsx) | 用表格软件查看 `sample_id`、`file_name` 两列 |
| [sample.csv](sample.csv) | 对照同名 Excel 文件，观察逗号分隔的文本与 Rainbow CSV 的列着色 |
| [sample.json](sample.json) | 复制后格式化副本，找到 `sample_id`、`figure` 和 `fictional` 字段 |
| [figure.svg](figure.svg) | 打开样品示意图；尺寸计算请使用带比例尺的测量图像 |

这组样例只用于课前检查。练习格式化时请先复制 JSON 文件，保留单行原件作对照。
