## Notebook：计算、文件编码和工具执行

打开[计算与工具调用.ipynb](计算与工具调用.ipynb)。在已有 Jupyter 环境或支持 Notebook 的编辑器中选择 Python 内核，使用“重启内核并运行全部”。教师课前完成环境准备，学生在课堂先观察演示。

所选 Python 环境需要 `ipykernel` 和 `matplotlib`；在本目录可用 `python -m pip install -r requirements.txt` 安装。若使用 VS Code，还需安装相应的 Python/Jupyter 扩展并选择该环境；也可以使用已有 Jupyter 服务。

演示内容：

1. 半径 2 mm 的圆面积约为 12.57 mm²。
2. 绘制半径与面积的曲线，修改半径观察圆点变化。
3. 读取课堂文本样例，打印第一行的二进制字节，再用 UTF-8 解码并核对汉字与字节的对应关系。
4. 用预先写好的 JSON 请求展示工具分发和实际计算。
5. 用负半径展示参数检查，最后对照公式核对。

Notebook 使用教师预写的模拟请求和回答模板，直接运行 Python 计算、绘图、请求解析与参数检查。课堂展示时将其明确标为**预写请求的模拟演示**；真实模型调用在后续 Agent 环节观察。
