## Notebook：计算、画图和工具执行

打开[计算与工具调用.ipynb](计算与工具调用.ipynb)。在已有 Jupyter 环境或支持 Notebook 的编辑器中选择 Python 内核，使用“重启内核并运行全部”。教师课前完成环境准备，学生先观察演示，不要求全班现场安装。

所选 Python 环境需要 `ipykernel` 和 `matplotlib`；在本目录可用 `python -m pip install -r requirements.txt` 安装。若使用 VS Code，还需安装相应的 Python/Jupyter 扩展并选择该环境；也可以使用已有 Jupyter 服务。

演示内容：

1. 半径 2 mm 的圆面积约为 12.57 mm²。
2. 绘制半径与面积的曲线，修改半径观察圆点变化。
3. 用预先写好的 JSON 请求展示工具分发和实际计算。
4. 用负半径展示参数检查，最后对照公式核对。

Notebook 不调用模型 API、不需要密钥。模拟请求和最后的回答模板由教师预写；计算、绘图、请求解析与参数检查实际由 Python 执行。不能把这部分展示为真实模型自主调用。
