# 本课 Markdown 公式速查

[返回课堂样例](README.md)

行内公式放在一对 `$` 之间，例如 `$A=\pi r^2$`。独立公式放在两对 `$$` 之间：

```markdown
$$
\sigma=\frac{F}{A_0}
$$
```

| 写法 | 显示含义 |
| --- | --- |
| `r^2` | 平方 |
| `A_0` | 下标 |
| `\frac{F}{A_0}` | 分数 |
| `\sqrt{x}` | 平方根 |
| `\alpha`、`\beta`、`\gamma` | α、β、γ |
| `\pi`、`\sigma`、`\mu` | π、σ、μ |

保存 Markdown 后打开预览，核对公式和单位。
