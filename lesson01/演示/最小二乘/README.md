# 最小二乘交互动画

配合[第 4 章第 2 节](../../内容/04_AI与Agent的工作方式/02_机器学习与最小二乘法.md)使用。

## 打开方式

下载后，用浏览器打开本目录的 `index.html`，并保留同目录下的 `demo.js`。所有计算在浏览器本地进行，无第三方库、联网请求、模型调用或服务端依赖。GitHub 的文件预览不执行此网页。

## 建议演示顺序

1. 初始 `a=1,b=0`，对照三个点计算 SSE=9。
2. 手动拖到 `a=1.5,b=0.5`，SSE=0.25。
3. 重置，播放自动拟合，看参数、残差、表格与损失曲线；可暂停、继续。
4. 点击直接求解，对照 `a=1.5,b=2/3,SSE=1/6`。
5. 显示新数据，讨论未参与训练的点与外推。

## 数值约定

- 训练点 `(1,2),(2,4),(3,5)`；检验点 `(4,6.5),(5,8.2)`，全部虚构、单位任意。
- 模型 `ŷ=ax+b`。梯度下降最小化 MSE，固定学习率 0.05，使用同时更新；绘制 SSE。
- 每 60ms 最多更新 4 次；最多 800 次或梯度范数小于 1e-6 时停止。
- 开始动画从当前参数继续；暂停可续播；手动修改、重置或直接求解会清空训练记录。
- 新数据不参与优化，也不用于宣布泛化成功或展示过拟合。
- 只显示实测与预测的竖直残差，不是正交距离；本例是普通最小二乘。
