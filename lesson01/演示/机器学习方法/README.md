# 真实化学测量数据：三种机器学习方法动画

配合[1.4.3 第 3 节](../../内容/1.4_AI与Agent的工作方式/1.4.3_聚类降维与分类.md)。下载本目录后，在浏览器打开 `index.html`，选择 K-Means、PCA 或 SVM，设置属性或主成分数；二维模式及 K-Means 可点击“播放”，高维 PCA 和 SVM 直接显示结果。页面从同目录读取 `style.css`、`wine-data.js` 和 `demo.js`，支持离线使用。

## 课堂操作

1. 在桌面端左侧菜单选择方法，再设置参与聚类的属性或保留的主成分数；右侧同时显示动画和结果。侧边栏随页面滚动保持可见，菜单较长时可单独滚动。窄屏将设置移到动画上方。
2. 点击“播放”观察过程；“暂停”和“单步”便于逐轮说明，“直接查看结果”显示最终结果。
3. 二维聚类的两幅图使用相同坐标。桌面端并排比较算法组别和真实品种，窄屏按顺序显示。圆点悬停信息包含样品编号和类别。
4. 三维及以上的 PCA 和 SVM 直接显示数值结果；高维 K-Means 仍可逐步更新品种对照表。
5. 点击“保存当前结果作对比”，再更换设置。页面保留各设置的结果；重复保存同一设置会更新原记录。刷新页面后记录清空。

属性少于两项时，页面提示补充属性；选择完成后恢复演示。参数变化会停止正在播放的动画，并清空该次计算的过程状态。已经保存的对比记录保持可见。

## 数据与处理

数据采用 Aeberhard 与 Forina 的 [UCI Wine 数据集](https://archive.ics.uci.edu/dataset/109/wine)，共 178 个样品、13 项化学测量指标，按 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 许可使用。浏览器数据来自 `sklearn.datasets.load_wine()`；`prepare_wine.py` 记录了提取和计算步骤。

- **K-Means**：选择 2–13 项属性（默认酒精和苹果酸），各自减去均值再除以标准差；固定分为三组，初始中心由确定性的最远点方法选取。动画逐步执行最近中心分配和组内均值更新。品种标签用于结果对照。
- **PCA**：对全部 13 项指标逐列标准化，可选择保留前 2–13 个主成分，并显示各主成分及累计解释方差比例。保留两个主成分时，动画先显示酒精与苹果酸的标准化散点图，再切换到主成分散点图；切换过程仅用于展示视图变化。
- **SVM**：用所选的前 2–13 个主成分及品种标签训练线性分类器。每个维度的模型由生成脚本预先计算；页面切换到对应模型。二维时显示分类边界，高维时显示训练集分类正确率及真实品种与预测品种的数量表。全部结果基于同一批 178 个训练样品。

所有点对应真实样品；K-Means 和 PCA 的二维坐标是从原始测量值计算得到的。页面中的组数、初始化和 SVM 参数用于课堂演示。

## 聚类与真实品种对照

K-Means 在选择两个属性时提供相同坐标下的真实品种散点图，以及随分组更新的品种数量表和组成色条。组编号与品种编号分别表示聚类输出和原始标签。页面尝试全部六种一一配对，用最大对应样品数除以 178 显示对应比例。

默认酒精和苹果酸组合在固定初始化收敛后的数量表为 `[[51, 7, 8], [7, 10, 32], [1, 54, 8]]`，行表示组别，列表示品种。最佳配对为组 1 → 品种 1、组 2 → 品种 3、组 3 → 品种 2，对应 137/178，约 77.0%。该比例用于描述本次聚类与真实标签的一致程度；两个属性对新样品的分类价值需要通过独立测试评估。

选择三项及以上属性时，K-Means 在全部所选维度中计算距离和中心，页面显示分组数量表和对应比例。PCA 和 SVM 保留三个及以上主成分时，页面显示数值结果。属性组合变化会改变距离尺度，组内距离平方和适合用来观察同一组合的迭代过程。

## 重新生成数据

具备 Python、NumPy 与 scikit-learn 的环境中，运行 `python prepare_wine.py` 可生成 `wine-data.js`。生成脚本使用 scikit-learn 内置的 UCI Wine 副本；课堂使用时请保留 `index.html`、`style.css`、`demo.js` 和 `wine-data.js` 四个文件。

数据引用：Aeberhard, S. & Forina, M. (1992). *Wine* [Dataset]. UCI Machine Learning Repository. [doi:10.24432/C5PC7J](https://doi.org/10.24432/C5PC7J)。

## 验证

运行 `node verify_demo.cjs` 检查 2–13 维计算、导出的分类数量表、图中点的坐标范围，以及播放、暂停、单步、直接查看、重置、属性选择和结果保存等交互状态。该检查使用模拟页面元素，页面布局与实际浏览器显示另行检查。
