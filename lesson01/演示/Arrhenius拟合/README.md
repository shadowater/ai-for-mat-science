# Arrhenius 最小二乘拟合

配合[1.4.2 第二节讲义](../../内容/1.4_AI与Agent的工作方式/1.4.2_机器学习与最小二乘法.md)。

数据来自 Stephen Lower 的 [Chem1 Virtual Textbook：Activation energy, Arrhenius law](https://chem1.com/acad/webtext/dynamics/dynamics-3.html) 中环丙烷异构化为丙烯的教学例题。仅摘录四组温度与速率常数，未复制原文或图像。来源未在例题中列出原始实验论文，课程按教材示例数据使用。

温度为 477、523、577、623 °C；对应速率常数为 0.00018、0.0027、0.030、0.26 s⁻¹。温度加 273.15 转为 K，计算倒数温度和速率常数数值的自然对数，再进行带截距的普通最小二乘拟合。

运行 `python3 fit_arrhenius.py`，无需第三方依赖。结果见[拟合结果](拟合结果.json)。脚本由本课程编写，使用未舍入的转换数值计算；讲义表格仅为显示而舍入。误差目标为对数空间中的残差平方和。四个点全部参与拟合，550 °C 的结果是插值预测，没有对应的独立实测值。

已有[最小二乘动画](../最小二乘/README.md)仍使用三点虚构数据，是独立的基础操作演示。
