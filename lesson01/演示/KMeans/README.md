# K-Means 分步演示

配合[第 4 章第 3 节](../../内容/04_AI与Agent的工作方式/03_KMeans与从数据中分组.md)。下载后用浏览器打开本目录 `index.html`，保留同目录 `demo.js`。演示由本地浏览器和随页脚本完成；GitHub 文件页只展示源文件。

## 课堂操作

1. 默认六点、K=2、方案 A，点击下一步分配，再点击下一步更新中心。
2. 初始中心 `(1,1),(7,7)`，分配后目标 J=4；更新为 `(4/3,4/3),(22/3,22/3)`，目标 J=8/3。
3. 播放或逐步继续直到稳定；切换方案 B 看初始化的影响。
4. 换八点矩形数据，K=2，对比方案 A 与 B：目标分别稳定到 4 与 74，说明局部解。
5. 改 K=3，讨论组数由谁指定，以及紧凑度目标与真实化学类别各自表达什么。

## 算法约定

- 原始数据固定，均为同尺度虚构坐标；显示轴等比例。
- 普通 K-Means / Lloyd 交替更新：最近中心分配，组内均值更新。目标为各点到所属中心的欧氏距离平方和。
- 方案 A 取第一个、中间和最后一个点，按 K 取前几个；方案 B 取第一个、第二个和最后一个点。
- 距离相等取编号较小的组。空组保留原中心，使后续中心计算继续使用有效数值；其他软件的策略可在各自文档中查阅。
- 至少更新一次中心后，重新分配保持原样时停止；另设 30 次更新上限，触发上限时提示教师检查收敛状态。
- 每 900ms 进行一次分配或一次中心更新。中间状态显示当时的实际目标值与中心。
- 修改数据、K 或初始化会重置。暂停后可手动继续或续播。
