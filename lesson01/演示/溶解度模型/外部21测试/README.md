# 固定 21 个化合物的外部测试

本实验将 Delaney 论文表 4 的 21 个化合物作为固定测试集。采用已确定的 4→8→1 网络与训练超参数，不根据这 21 个结果调整模型。原随机划分实验保留在上一级目录。

## 结构与重叠排除

表 4 的实测 logS 保持原值。结构通过 PubChem PUG REST 检索，通常使用原表 CAS；diazinon 原表 CAS 有误，改用名称检索。21 条均得到单条结构记录，见[含结构的数据](../原论文验证数据/table4_21_with_structures.csv)与[检索记录](../原论文验证数据/结构检索结果.json)。每条记录保留 CID 和请求 URL，获取日期为 2026-11-16。

用 RDKit 清理结构、取主体片段、中和电荷、移除立体标记并规范化互变异构体，生成用于排除重叠的键；另外排除同名记录。去除立体标记是保守排除策略，四项描述符本身也不表达立体构型。描述符仍从原输入结构计算，标准化结构仅用于分组与重叠检查。

共排除 **20 条 Small 记录**，包括 Antipyrene/antipyrine、Ethyl-p-aminobenzoate/benzocaine、5-Ethyl-5-phenylbarbital/phenobarbital 等别名。排除清单在[结果.json](结果.json)中。剩余 **1,124 条**按结构分组划分为：训练 724、验证 179、内部测试 221。外部 21 条与这三个集合在本次规范化规则下均无结构键重叠。

PubChem 补充的是标准结构，原论文没有提供逐条 SMILES；chlordane 等名称涉及异构体或组成差异，原测量材料的具体组成仍受原表信息限制。互变异构体枚举出现过候选结构警告和达到转换次数上限的提示，运行未丢弃记录；这里的无重叠结论限于本次匹配规则，不等于完成了所有化学身份的人工审计。

## 训练与结果

只在训练集拟合标准化参数。验证集选择第 **230** 轮的网络参数，第 **380** 轮停止。内部测试和外部 21 条均不参与参数更新或停止轮次选择。

| 模型 | 外部 21 条 MAE | 外部 21 条 RMSE | 外部 21 条 R² |
| --- | ---: | ---: | ---: |
| 重新拟合的线性回归 | 0.789 | 1.012 | 0.719 |
| 4→8→1 神经网络 | 0.731 | 0.942 | 0.757 |

本次网络 RMSE 比线性模型低约 6.9%。21 个样品规模较小，结果不代表所有化学体系。

原表 ESOL 预测值在同一组标签上的 MAE 为 0.688、RMSE 为 0.873。原模型使用了更大的训练集合、不同的描述符实现，而且其中有与 Small 重叠的化合物，因此这组原表数值只作为文献参考，不能当作相同训练条件下的公平对比。这里的 R² 按 `1-SSE/SST` 计算，与论文的相关系数平方不一定相同。

## 使用

在上一级目录运行：

```bash
python train.py --external21
python predict.py 'CCO' --model 外部21测试/模型参数.json
```

- [外部21预测.csv](外部21预测.csv)：逐个化合物的实测与预测。
- [模型参数.json](模型参数.json)：本次重训参数。
- [结果.json](结果.json)：排除记录、数据划分及全部指标。
- [训练过程.csv](训练过程.csv)：训练与验证 MSE。
- [样本与预测.csv](样本与预测.csv)：排除重叠后的内部数据划分与预测。
- [训练与测试.png](训练与测试.png)：训练曲线及 **221 条内部测试集**的散点图，外部 21 条结果见单独 CSV。
