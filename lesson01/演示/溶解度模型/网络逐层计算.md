# 溶解度神经网络的逐层运算

[返回第四小节（1.4.4）](../../内容/1.4_AI与Agent的工作方式/1.4.4_从手工特征到深度神经网络.md) · [打开交互演示](交互演示/index.html)

本附件对应固定外部 21 个化合物实验中选定的第 230 轮模型。网络结构为 **4→8→1**，隐藏层使用 tanh，共 49 个可训练参数。下列数值保留六位小数；计算与网页使用[模型参数文件](外部21测试/模型参数.json)中的完整精度。

## 1. 输入：一个分子的四项描述符

按固定顺序排列输入：

$$\mathbf{x}=[x_1,x_2,x_3,x_4]^\mathsf{T}
=[\mathrm{logP},\mathrm{MW},\mathrm{RB},\mathrm{AP}]^\mathsf{T}.$$

这四项数值分别为计算的辛醇／水分配系数对数、分子量、可旋转键数、芳香重原子比例，由 RDKit 根据分子结构计算。目标为 $y=\log_{10}[S/(\mathrm{mol\,L^{-1}})]$。

## 2. 标准化：把四项输入换算到相近尺度

$$\tilde x_i=\frac{x_i-\mu_i}{\sigma_i}.$$

均值 $\mu_i$ 和标准差 $\sigma_i$ 只由 724 条训练记录计算，预测时保持固定。

| 输入 | 均值 $\mu_i$ | 标准差 $\sigma_i$ |
| --- | ---: | ---: |
| logP | 2.468126 | 1.893790 |
| MW | 204.129620 | 101.831194 |
| RB | 2.128453 | 2.674066 |
| AP | 0.369603 | 0.344070 |

## 3. 隐藏层：四个数变成八个数

每个隐藏单元先计算四项输入的加权和，再加偏置：

$$a_j=w_{j1}\tilde x_1+w_{j2}\tilde x_2+w_{j3}\tilde x_3+w_{j4}\tilde x_4+b_j.$$

八个单元各有一组参数，全部列在下表中：

| 单元 | $w_{j1}$ | $w_{j2}$ | $w_{j3}$ | $w_{j4}$ | $b_j$ |
| --- | ---: | ---: | ---: | ---: | ---: |
| $a_1$ | 0.007403 | 0.333965 | -0.117152 | 0.050607 | -0.188457 |
| $a_2$ | 1.812186 | -1.724800 | -0.041311 | -0.029818 | -1.748736 |
| $a_3$ | 0.350905 | -0.156839 | -0.110803 | -0.108897 | 0.840419 |
| $a_4$ | -0.812690 | 0.475880 | -0.197674 | 0.026844 | 0.699065 |
| $a_5$ | -0.384538 | 0.782489 | -0.114323 | 0.372766 | -0.104493 |
| $a_6$ | -0.714298 | 0.031485 | -0.428304 | 0.120125 | -0.306630 |
| $a_7$ | -0.068108 | -0.894034 | -1.272257 | 0.008176 | -0.100354 |
| $a_8$ | 1.077047 | -1.489755 | -0.324080 | 0.058008 | -0.424666 |

每个加权和再经过同一个激活函数，得到八个隐藏层输出：

$$h_j=\tanh(a_j)=\frac{e^{a_j}-e^{-a_j}}{e^{a_j}+e^{-a_j}},\qquad j=1,\ldots,8.$$

使用列向量时，这一步可以合写为：

$$\mathbf h=\tanh(W\tilde{\mathbf x}+\mathbf b),\qquad
W\in\mathbb R^{8\times4},\quad\mathbf b,\mathbf h\in\mathbb R^8.$$

tanh 分别作用于八个分量。参数文件的 `weights[0]` 按“输入 × 隐藏单元”保存，是一个 4×8 数组，与这里的 $W$ 互为转置。文件的 `weights[0][i][j]` 对应数学式中的 $w_{j+1,i+1}$，数组下标从 0 开始。

## 4. 输出层：八个数变成一个数

$$\hat{\tilde y}=v_1h_1+v_2h_2+v_3h_3+v_4h_4+v_5h_5+v_6h_6+v_7h_7+v_8h_8+c.$$

| 参数 | 数值 |
| --- | ---: |
| $v_1$ | -0.592501 |
| $v_2$ | -1.041146 |
| $v_3$ | -0.911637 |
| $v_4$ | 0.728895 |
| $v_5$ | -0.684588 |
| $v_6$ | 0.640834 |
| $v_7$ | -0.342900 |
| $v_8$ | 0.675130 |
| $c$ | -0.389631 |

输出层直接进行加权求和，得到标准化尺度下的预测值。该层没有 tanh 变换。

## 5. 还原输出：得到预测 logS

$$\widehat{\log S}=\mu_y+\sigma_y\hat{\tilde y}.$$

本模型中，$\mu_y=-3.074888$，$\sigma_y=2.123962$。若需要浓度值，再计算 $\hat S=10^{\widehat{\log S}}\,\mathrm{mol\,L^{-1}}$。

完整函数可以写成：

$$\widehat{\log S}=\mu_y+\sigma_y\left[\mathbf v^\mathsf{T}
\tanh\left(W\tilde{\mathbf x}+\mathbf b\right)+c\right].$$

## 6. 改一个参数，输出怎样变化

固定其余参数，把输出偏置 $c$ 增加 0.1：

$$\Delta\widehat{\log S}=0.1\sigma_y\approx0.212396.$$

所有样本的预测溶解度都会变为原来的约 1.63 倍。改变输出权重 $v_j$ 时，则有：

$$\Delta\widehat{\log S}=\sigma_yh_j\Delta v_j.$$

各分子的隐藏输出 $h_j$ 不同，因此同一个权重调整对不同分子的影响不同。改变隐藏层权重时，局部变化率为：

$$\frac{\partial\widehat{\log S}}{\partial w_{ji}}
=\sigma_yv_j(1-h_j^2)\tilde x_i.$$

这个式子来自链式法则：依次经过输出尺度、输出权重、tanh 导数和输入分量。

在[交互演示](交互演示/index.html)中，先选一个验证集样本，观察各层数值；点击“输出偏置 c 增加 0.1”，比较预测变化，再撤销修改。也可以选择一个隐藏层权重，观察不同样本的预测如何变化。

## 7. 训练改变哪些数值

训练更新 $W$ 的 32 个权重、$\mathbf b$ 的 8 个偏置、$\mathbf v$ 的 8 个权重和 $c$，合计 49 个参数。输入、实测标签以及标准化统计值保持固定。

程序用标准化目标计算平方误差，并加入 L2 权重惩罚；反向传播计算梯度，Adam 根据梯度更新参数。网页的训练曲线使用还原到 logS 尺度的均方误差，便于解释。每一轮遍历训练集后保存一次参数；这些参数用于回放真实训练过程。

验证集选择第 230 轮，训练在第 380 轮停止。网页中手动修改的参数只是一次探索；若根据测试结果反复调参，这些测试样本就参与了模型选择，后续评价需要另留数据。
