# 溶解度网络交互演示

直接用浏览器打开 [index.html](index.html)。请将 `index.html`、`app.js` 和 `data.js` 保留在同一目录。页面不需要联网、Python 服务或 GPU；GitHub 的文件预览不会执行页面，需先下载到本地打开。

## 观察训练与修改参数

1. 将训练轮数拖到第 1 轮，点击“播放训练”，观察训练与验证误差及参数颜色的变化。
2. 点击“查看选定模型”，载入第 230 轮参数。切换外部测试集可核对 MAE 约 0.731、RMSE 约 0.942。
3. 切回训练集或验证集，点击参数表中的任意一个数值，通过滑块或数值框修改。预测指标、散点图和样本逐层计算会立即更新。
4. 点击“输出偏置 c 增加 0.1”，观察所有预测 logS 增加约 0.2124；点击“撤销手动修改”恢复当前轮的原始参数。
5. 选择一个分子，查看原始描述符、标准化输入、八个隐藏单元及最终输出。完整公式见[逐层运算附件](../网络逐层计算.md)。

“播放训练”回放 Python 实际训练得到的 380 组参数，包含每轮结束时的权重与偏置。浏览器即时执行前向计算；手动修改不会启动重新训练。播放或切换轮数会清除手动修改。

训练曲线保持为原训练记录。当前预测指标与散点图随参数变化，“本轮原始 RMSE”用于对照修改前后的效果。标准化统计值始终来自训练集。测试集只用于最终评价，不应依据测试结果选择参数。

“导出当前参数”保存与 `predict.py --model` 兼容的 JSON，并标记来源轮数及是否手动修改。它不覆盖原模型文件。

## 数据与复现

本演示使用[固定外部 21 测试实验](../外部21测试/README.md)：训练 724 条、验证 179 条、内部测试 221 条、外部测试 21 条。数据来源、描述符与结构重叠处理见该说明。

安装上一级 `requirements.txt` 的依赖后运行：

```bash
python build_demo.py
```

构建程序从已保存的样本划分与标准化参数重现训练，逐轮核对训练误差，核对第 230 轮全部参数，并核对 1,145 条内部与外部预测，再生成 `data.js`。若库版本变化导致结果不一致，核对会报错；此时需要检查实验环境。页面展示的模型参数保留完整浮点精度，表格仅四舍五入显示。
