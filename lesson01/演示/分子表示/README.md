# 分子连接环境示意

配合[1.4.4 第 4 小节](../../内容/1.4_AI与Agent的工作方式/1.4.4_从手工特征到深度神经网络.md)。本地浏览器打开 `index.html`，保留 `demo.js`。演示直接在本地浏览器运行，使用静态页面和脚本。

## 操作

先看相同分子式，再依次点 0、1、2 步。左侧碳在两张图中都是碳，一步邻居却分别是碳和氧。自动演示每 1.4 秒切换一次，从 0 步走到 2 步停止；手动选择会停止自动演示。

## 边界

- 展示省略氢的重原子图，所有键均为单键；平面排布用于展示连接关系，三维几何需要另外的空间坐标。
- 高亮范围由图遍历实时计算，表示局部连接环境；网络权重、注意力和学习到的向量由实际模型训练产生。
- 演示覆盖 0、1、2 步邻域范围；图神经网络、Uni-Mol 和溶解度预测分别需要实际模型与计算流程。
- 元素计数和分子量使两者相同，连接环境使两者具有区别；ESOL 的四个描述符还需逐项计算和比较。
- 本图用于理解局部连接环境传播；Uni-Mol 的 Transformer 结构由模型论文和代码展示。

图示、代码与教学文字均为课程编写。相关研究阅读：[Duvenaud 等 2015](https://arxiv.org/abs/1509.09292)、[Uni-Mol 官方仓库](https://github.com/deepmodeling/Uni-Mol)。第三方研究内容通过链接供读者查看。
