# 分子连接环境示意

配合[第 4 小节](../../内容/04_AI与Agent的工作方式/04_从手工特征到深度神经网络.md)。本地浏览器打开 `index.html`，保留 `demo.js`。无安装、联网或模型调用需求。

## 操作

先看相同分子式，再依次点 0、1、2 步。左侧碳在两张图中都是碳，一步邻居却分别是碳和氧。自动演示每 1.4 秒切换一次，从 0 步走到 2 步停止；手动选择会停止自动演示。

## 边界

- 只展示省略氢的重原子图，所有键均为单键；平面排布不代表三维几何。
- 高亮范围由图遍历实时计算，不是网络权重、注意力或学习到的向量。
- 不运行图神经网络、Uni-Mol 或性质预测，不生成溶解度数值。
- 仅用元素计数与分子量的描述会混淆两者；不能据此声称 ESOL 的四个实际描述符也完全相同。
- 只是解释局部连接环境传播的辅助示意，不等同于 Uni-Mol 的 Transformer 结构。

图示、代码与教学文字均为课程编写。相关研究阅读：[Duvenaud 等 2015](https://arxiv.org/abs/1509.09292)、[Uni-Mol 官方仓库](https://github.com/deepmodeling/Uni-Mol)。没有复制第三方图片或代码。

验证：已检查邻接关系、不同起点的 0/1/2 步覆盖范围、手动切换、自动停止及手动打断播放；JavaScript 语法、本地链接和讲义手算结果通过。真实浏览器画面尚未人工验看，授课前需确认显示布局。
