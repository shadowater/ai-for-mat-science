# 典型词向量案例：把真实数字展开看

使用部署的 **Qwen3-0.6B Q8_0**，直接读取 `token_embd.weight`。每个 token 对应一个 **1,024 维向量**。下面的数来自实际量化权重反量化后的 float32，不是随机示意值，也没有请模型口头生成这些数字。

## 先看怎样做向量加减

向量加减是逐个分量计算。例如：

$$q_i=v(\text{伦敦})_i-v(\text{英国})_i+v(\text{法国})_i,\qquad i=1,\ldots,1024$$

得到的仍是 1,024 个数，再与词表中各 token 的向量比较余弦相似度，寻找最近者。以下检索都在完整词表中进行，并排除三个输入 token。

下表只展示运算后的最近词，不列运算前排名：

| 关系 | 向量运算 | 最近 token | 运算结果与目标词向量的余弦相似度 |
| --- | --- | --- | --- |
| 国家与首都 | 伦敦 − 英国 ＋ 法国 | 巴黎 | 0.621 |
| 亲属称谓 | 父亲 − 母亲 ＋ 妈妈 | 爸爸 | 0.827 |
| 英文比较级 | ␠bigger − ␠big ＋ ␠small | ␠smaller | 0.756 |
| 英文进行式 | ␠walking − ␠walk ＋ ␠run | ␠running | 0.711 |

余弦相似度不是概率，0.827 不表示有 82.7% 的正确率。最近词命中也不表示运算结果逐项等于目标向量。

## 完整向量在哪里？

- [完整向量 JSON](典型案例完整向量.json)：16 个词各 1,024 个分量，另含四组运算结果和两组差向量，均保留完整数值。
- [词向量 CSV](典型词向量.csv)：每行一个词，依次为 token、编号和 d1—d1024；可用表格软件查看。
- [导出代码](export_examples.py)：可从模型文件重新提取和核对。

以下每个表格只显示**前 8 个分量，四舍五入至小数点后 6 位**；省略号代表剩余 1,016 个分量。所有近邻和相似度计算使用完整向量，不是只用这 8 个数。

英语中的 `␠` 表示真实前导空格 U+0020：`␠big` 与不带空格的 `big` 是不同 token。JSON 和 CSV 保留真实空格，不用这个可视标记替换。

## 案例 1：国家与首都

计算 **伦敦 − 英国 ＋ 法国**，检索得到 **巴黎**。

| 向量 | 前 8 个分量 |
| --- | --- |
| v(伦敦)，token 107074 | `[0.030367, -0.060735, -0.001938, 0.041351, -0.029721, -0.041351, 0.045874, 0.068488, …]` |
| v(英国)，token 104025 | `[0.016235, -0.044647, 0.017757, 0.052258, 0.000000, -0.054287, -0.011162, 0.064434, …]` |
| v(法国)，token 104328 | `[-0.014647, -0.052309, 0.031385, 0.043417, -0.011508, -0.025108, -0.002092, 0.062248, …]` |
| 运算结果 q | `[-0.000515, -0.068397, 0.011690, 0.032510, -0.041229, -0.012173, 0.054944, 0.066302, …]` |
| v(巴黎) | `[-0.006843, -0.063636, -0.008895, 0.047898, -0.019844, -0.044477, 0.040371, 0.070479, …]` |

只看第 1 个分量：`(0.030367) − (0.016235) + (-0.014647) ≈ -0.000515`。其余 1,023 个位置执行同样的逐项计算。

完整 q 与目标向量的余弦相似度为 **0.621**；两组差向量 `v(伦敦)−v(英国)` 和 `v(巴黎)−v(法国)` 的余弦为 **0.476**。这两个指标比较的对象不同，不应混用。

可以解释为：将“英国到伦敦”的关系用于法国，在这次词表检索中得到巴黎。不是把“英国”这个词从现实城市中物理删除。

| 运算结果 q | `[0.003991, -0.050640, 0.001517, 0.003715, 0.053371, -0.028906, -0.005957, 0.072002, …]` |
| v(爸爸) | `[0.026578, -0.053156, -0.014575, 0.019719, 0.017147, -0.034294, 0.016290, 0.071160, …]` |

可以解释为：两种亲属称谓体系中的对应关系，在这些词的表示里具有一定的方向相似性。不要给每个坐标直接贴上“性别”“年龄”等标签。

## 课堂怎样讲？

1. 先提出文字关系，请学生预测第四个词。
2. 展示其中一行真实向量：每个词在这里就是 1,024 个可计算的数。
3. 只手算第一个分量，说明程序会对全部位置做相同操作。
4. 展示完整向量检索结果，再对照目标向量：接近不等于完全相同。

单个分量本身通常没有清晰的人类标签。我们检查的是整体表示中可以观察到的关系，不是预先把“首都”“比较级”等写进某一列。

## 资料与适用范围

关系类别参考 [Word2Vec 作者题库](https://github.com/tmikolov/word2vec/blob/master/questions-words.txt)及 [Mikolov 等原论文](https://arxiv.org/abs/1301.3781)。这些类别提供了寻找案例的思路；本页数字来自我们部署的 Qwen 模型，不是 Word2Vec 的结果。
