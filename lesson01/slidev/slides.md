# GUI、CLI、TUI：不同的交互方式

| 界面 | 操作方式 | 例子 |
|---|---|---|
| GUI | 窗口、按钮、鼠标 | 文件管理器 |

# 写代码与运行代码，是两件事

编辑器 → `.py` 文件 → Python 解释器 → 输出

Notebook 页面 → 内核 → 变量状态 / 输出

- 保存代码，不等于保存内核里的所有变量
- 重启内核并从头运行，检查是否漏了步骤
- CPython 通常先编译为字节码，再执行

# 检查比“运行成功”更重要

- 数值：100 N / 2 mm² = 50 MPa
- 单位：N/mm² = MPa；cm² 不能直接混用
- 输入：面积必须为正；缺失列应报错
- 证据：输出文件存在，来源与参数有记录
- 重现：从空内核重新运行得到同样结果

# 时间也要算进成本

示例假设：手动 10 分钟/次。

自动化：首次整理 40 分钟，之后每次运行与核验 2 分钟。

累计 5 次约打平；更多重复才逐步省时。

工具费用、维护、失败重试也要算；付费 token 是可选投资。
