# 1.5 课堂实践与结果检查

[返回第一课入口](../README.md)

本节使用已配置的 Agent 读取课堂样例并生成文件。[最小 Harness 演示](../演示/最小Harness/README.md)展示模型请求、工具执行和结果反馈。

打开[第一课课堂样例](../课堂样例/README.md)，其中包含样品记录、图片、公式和文献记录。向 Agent 发送以下任务：

> 读取 `课堂样例/sample.json`、`课堂样例/note.zh.md` 和 `课堂样例/paper-record.zh.md`，生成一份新的 Markdown 笔记。写入样品编号、`figure.svg` 图片、给定公式和文献来源，保存为新文件，并告诉我保存路径。

完成后检查输出文件：

- 核对样品编号、图片引用、公式和文献来源与输入材料是否一致。
- 打开 Markdown 预览，检查标题、图片和公式的显示。
- 查看 Agent 的工具记录，确认文件已经写入指定路径。
- 用[比例尺练习图](../课堂样例/比例尺练习.svg)核对换算：100 像素对应 10 μm，30 像素对应 3 μm。

求助时说明目标、已执行的操作和实际结果；出现报错时保留报错原文。最后提交保存的输出文件和核对结果。

整理自己的科研问题时，可以使用[科研任务模板](科研任务模板.md)记录已有资料、待确认信息和下一步工作。
