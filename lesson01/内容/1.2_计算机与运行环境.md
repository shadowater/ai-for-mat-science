## 1.2.1 硬件：计算与存储

**硬件**是计算机的物理部件，包括处理器、内存和存储设备。更多硬件基本知识见《你缺失的那门计算机课》的[“认识你的电脑”](https://www.criwits.top/missing/computer-and-its-components.html)。

> **CPU（Central Processing Unit，中央处理器）**负责执行程序指令；**GPU（Graphics Processing Unit，图形处理器）**擅长并行处理图形和其他大量相似的运算。
>
> **RAM（Random Access Memory，随机存取存储器）**通常指运行内存；**VRAM（Video Random Access Memory，视频随机存取存储器）**通常指显卡上的显存。

| 部件 | 作用 | 例子 |
| --- | --- | --- |
| CPU（中央处理器） | 执行通用程序指令，处理控制流程和各种计算 | 启动应用、判断条件、组织文件处理步骤 |
| GPU（图形处理器） | 擅长同时处理大量相似的运算 | 绘制游戏画面、处理图像、加速适合并行的模型计算 |
| 内存（RAM） | 程序当前工作的空间，临时放指令和数据 | 打开图片、运行程序和编辑中的文字 |
| 显存（VRAM） | 供 GPU 使用的工作存储空间 | 放图像、模型参数和计算中间结果 |
| 存储设备 | 保存程序和文件，断电后仍可保留数据 | 保存课程文件夹、原始数据和输出图片 |

CPU 是执行通用程序指令的芯片。GPU 是擅长并行运算的处理器，可用于图像处理和模型计算。
独立显卡通常由 GPU、显存、电路板和散热部件组成。

### 1.2.1.1 CPU 与 GPU 的分工

绘制一幅图像时，计算机要为大量像素确定颜色；绘制三维画面时，还要计算物体的位置、形状和光照。画面中的许多位置可以同时进行相似的计算。GPU 围绕这类图形任务发展，因此称为**图形处理器**。

CPU 擅长组织程序和处理各种执行步骤；GPU 擅长把大量相似的运算并行完成。

### 1.2.1.2 内存与存储设备的分工

处理器执行计算，内存保存程序当前使用的数据，存储设备长期保存文件。下图用批改作业的场景表示这三个环节。

<img src="素材/02_计算机与运行环境/你缺计课PDF/批改作业.png" alt="老师从桌子一侧取出作业，在中央批改后放到另一侧的三步示意" width="620">

> **SSD（Solid State Drive，固态硬盘）**使用闪存保存数据；**HDD（Hard Disk Drive，机械硬盘）**使用磁性盘片保存数据。
>
> **OOM（Out of Memory，内存不足）**指程序申请内存时，可用内存无法满足需求的情况。

内存通常比 SSD、HDD 有更低的访问延迟和更高的访问速度，适合程序反复读写，断电后内容会消失。存储通常单位容量成本更低、容量更大，可以持久保存文件。

- **机械硬盘（HDD）**：使用旋转的磁性盘片和机械磁头读写数据。
- **固态硬盘（SSD）**：使用闪存芯片读写并保存数据。

下图把一块 500 GB 硬盘划分为 175 GB 和 325 GB 两个分区。

> **GB（Gigabyte，吉字节）**是常见的存储容量单位，硬盘标称容量通常按十进制计算：1 GB = 10 亿字节。

<img src="素材/02_计算机与运行环境/你缺计课PDF/硬盘分区.png" alt="一块 500 GB 硬盘被划成 175 GB 和 325 GB 两个分区的示意" width="680">

保存笔记时，程序将修改后的内容写入存储；关闭后重新打开，可以读取已保存的内容。

### 1.2.1.3 显存

显存对于 GPU 来说读写通常比内存还快，因此一般在GPU上的计算倾向于把数据放到显存里面。

## 1.2.2 软件：程序、文件与运行环境

**软件**是让计算机完成任务的程序及相关数据。**操作系统**管理硬件资源、文件和运行中的程序；Windows、macOS 和 Linux 都是操作系统，具体来说是桌面操作系统，而安卓，iOS，鸿蒙则是移动端操作系统。
> **VS Code（Visual Studio Code）**是本课使用的代码编辑器。**Agent（智能体）**可根据任务调用模型和工具。

VS Code、浏览器和 Agent 属于应用软件，依靠操作系统提供的功能使用硬件。

### 1.2.2.1 图形界面和命令行

**通过命令与计算机进行交互**

> **GUI（Graphical User Interface，图形用户界面）**通过窗口、图标等元素接收操作；**API（Application Programming Interface，应用程序编程接口）**定义程序之间交换请求和结果的方式。
>
> **CMD（Command Prompt，命令提示符）**是 Windows 的命令解释程序；**Shell（命令解释程序）**负责读取并执行输入的命令。

平时点击图标、拖动文件，是通过**图形界面（GUI）**操作；输入命令，则是通过**命令行**操作。二者最终都由软件调用系统功能来完成任务。

自动化工具可以通过视觉识别或软件接口操作界面；界面位置和窗口状态的变化会影响视觉操作。命令或 API 能把目标和参数写得更明确，也便于重复执行。**终端（terminal）**提供文字交互入口，**Shell**解释命令；本课演示的 Windows CMD 就是一种命令解释器。

#### 1.2.2.1.1 新建并改名文件夹

`Ctrl+反引号` 可以在 VS Code 中打开或关闭终端。

`Ctrl+Shift+反引号` 可以新建终端。

<img src="素材/02_计算机与运行环境/VS_Code终端.png" alt="VS Code 内置终端，当前使用 PowerShell" width="680">

截图中的终端使用 PowerShell。以下两条命令可在 Windows 的 PowerShell 或 CMD 中执行。


第一行创建 `lesson-demo` 文件夹，第二行将其改名为 `lesson-data`。执行后可在vscode文件浏览器中查看结果。命令说明：[mkdir](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/mkdir)、[ren](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/ren)。

命令由名称和参数组成。`ren` 后面的两个参数依次是旧名和新名。

### 1.2.2.2 Notebook 中的Python代码运行过程

> **Jupyter Notebook** 是交互式计算文档，可以在同一个文件中保存代码、公式、图表和说明；文件后缀为 `.ipynb`。**Python 内核**负责执行文档中的代码单元格。


计算机里面只有0和1，对应着数字电路用高、低电压范围等可区分的物理状态表示逻辑值。
<img src="素材/00_通用/零与一横幅.jpg" alt="写有‘你是 0，我是 1，携手共创计算机’的横幅" width="480">


让我们打开[课堂 Notebook](../演示/计算与文件编码.ipynb)，使用“运行全部”依次执行。**Notebook**在同一文档中组织说明、代码单元格和输出；连接的 **Python 内核**负责执行代码。

先观察半径为 2 mm 的圆面积：

```python
import math
radius_mm = 2.0
area_mm2 = math.pi * radius_mm ** 2
print(round(area_mm2, 2))
```

结果约为 `12.57 mm²`。将半径从 2 改为 3 后重新运行，输出的面积和曲线随之变化。

#### 1.2.2.2.1 Python 代码的执行过程

以常见的 **CPython** 实现为例，源码经过语法分析和编译，形成解释器使用的**字节码**，再由解释器执行。解释器和它调用的底层库本身运行在 CPU 上；涉及文件、窗口等功能时，还会借助操作系统。参考 [Python 官方术语表中的 bytecode](https://docs.python.org/3/glossary.html#term-bytecode)。

> **CPython** 是 Python 语言最常用的实现。**字节码（bytecode）**是 Python 解释器执行的中间指令形式。

```mermaid
flowchart TD
    A["Notebook 中的 Python 源码"] --> B["Python 内核：本例使用 CPython"]
    B --> C["分析语法并编译为字节码"]
    C --> D["解释器执行字节码，调用底层库"]
    D --> E["解释器与底层库的机器指令由 CPU 执行"]
    D --> F["文件等操作经操作系统完成"]
    F --> E
    E --> G["芯片上的电子电路改变状态"]
```

> **寄存器（processor register）**是处理器内部用于暂存指令、地址或计算数据的高速存储单元。

### 1.2.2.4 环境变量、PATH 与快捷方式

**环境变量**是运行中的程序可以读取的一组“名称—值”设置。它们可以告诉程序服务地址、配置位置等信息，通常在启动时继承

> **PATH（路径）**是环境变量名，值由一组目录组成。**URL（Uniform Resource Locator，统一资源定位符）**是网络资源或接口的地址。

PATH 列出系统查找可执行程序的目录。输入命令名后，系统沿 PATH 查找程序。快捷方式保存目标位置，供用户打开相应程序或文件。

在 VS Code 命令行入口已加入 PATH 的电脑上，打开 CMD 并输入：

```bat
code .
```

`code` 是命令名，`.` 表示当前目录。命令会让 VS Code 打开当前目录。那么计算机怎么知道我们要打开vscode的呢？

在 CMD 中输入 `where code`，可以查看系统找到的命令入口。使用完整路径启动时，需要输入该入口在本机的实际路径。
