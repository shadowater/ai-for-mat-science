# 第一课课件：使用说明与两种方式比较

## 建议用法

授课主线使用 Slidev，学生上机使用 Notebook。两套内容对应同一教学大纲，方便试讲后决定是否统一。交互目标是让学生先预测、再修改、最后验证，不为动画增加无关步骤。

| 能力 | Slidev（27 页） | Notebook 转换版（28 页） | Jupyter + RISE |
|---|---|---|---|
| 概念讲授、翻页 | 支持，Slidev 原生切换 | 支持，键盘左右翻页 | 需要安装 RISE |
| 程序/Agent 分步动画 | 嵌入交互页面 | 嵌入同一页面 | 打开 Notebook 中的演示链接 |
| 截面积滑块与曲线 | 支持 | 支持 | 演示链接；也可改代码参数重跑 |
| Python 现场执行 | 嵌入本机运行器 | 嵌入同一运行器 | 真正的 Notebook 内核 |
| 状态与文件 | 演示运行器每次独立进程 | 同左；另展示预先执行的输出 | 保留变量状态，读写课堂文件 |
| 讲者备注 | 源码中附备注，Slidev 演讲者模式 | 按 N 展开/收起 | notes 类型单元格 |
| 不安装 Node 即播放 | 已提供 dist，需要本地 HTTP 服务 | 可直接打开 HTML 阅读；代码需服务 | 需要 Python/Jupyter 环境 |
| 此次验证 | 构建通过，浏览器未验收 | 转换完成，浏览器未验收 | 依赖安装失败，未验证 RISE |

Notebook 转换版由随附的轻量脚本从 `.ipynb` 生成，**不是 nbconvert 产物**；其 Python 单元格展示已执行输出，不会自动连接 Jupyter 内核。嵌入演示区另有明确的“运行 Python”按钮，调用本机运行器。后续如需标准 Reveal.js 导出，可使用下文 nbconvert 命令。

## 最快试讲：使用已经构建的文件

将整个 `lesson01` 文件夹复制到授课电脑。打开终端进入该目录：

```bash
python scripts/demo_server.py
```

Windows 也可使用 `py -3 scripts/demo_server.py`；macOS/Linux 也可使用 `python3 scripts/demo_server.py`。打开浏览器访问：

http://127.0.0.1:8765/

首页可选择 Slidev 或 Notebook 转换版。服务启动后，现成课件、动画、滑块和短 Python 演示均不依赖互联网，也不需要 AI API Key。本机 Python 使用标准库即可运行短演示；完整 Notebook 绘图需安装 matplotlib。

本机运行器只监听 127.0.0.1，带同源会话校验，8 秒执行超时。它运行的是本机 Python，不是安全沙箱，适合教师自己的课堂代码；不要开放给公网。每次运行使用临时工作目录与新进程，不保留上次变量，也不能用相对路径直接读取课程 CSV。文件处理的完整示例在 Notebook 中执行。

停止服务：终端 Ctrl+C。端口被占用时先关闭原演示服务；课件中的演示链接固定为 8765。

## Notebook：真正编辑、执行和演示

在你选择的课程 Python 环境中（建议独立环境）安装：

```bash
python -m pip install -r requirements-teaching.txt
python -m jupyterlab
```

在 JupyterLab 打开 `notebook/lesson01.ipynb`，选择 Python 内核，先执行“Restart Kernel and Run All Cells”。Notebook 顶层目录应为 `lesson01` 或其 `notebook` 子目录。安装 RISE 后使用其演示入口进入幻灯模式；返回编辑模式修改单元格并执行。该入口的具体 UI 随扩展版本可能变化。

代码单元格包括：温度换算、工程应力最小函数、CSV 读取/验证/计算/保存/绘图。后者生成 `outputs/stress.csv`、`stress.png` 和 `processing.txt`。所有数值来自教学模拟数据。面积变量改为 4 后重新运行即可观察曲线变化。

如果选择传统 nbconvert 导出：

```bash
python -m jupyter nbconvert notebook/lesson01.ipynb --to slides --output lesson01.reveal
```

该命令会生成 `lesson01.reveal.slides.html`，避免覆盖本次自带转换版。普通导出的 HTML 没有 Python 内核；Reveal.js 前端资源是否离线可用需按 nbconvert 配置另行检查。RISE 与“导出 HTML”是两条不同的路径。

## 修改与重建 Slidev

授课电脑需准备支持 Slidev 53 的 Node（本次构建使用 Node 24.14.1）。进入 `slidev`：

```bash
npm install
npm run dev
```

另一个终端继续运行 Python 演示服务。也可以用 `npm run build` 重建 `dist`，再通过首页播放。仓库已包含构建好的 `dist`，但不包含 `node_modules`；首次重新构建时，`npm install` 需要联网下载依赖。

为了同步两套课件，建议修改 `scripts/build_materials.py` 中的教学序列，然后从 `lesson01` 运行：

```bash
python scripts/build_materials.py
python scripts/execute_notebook.py
node scripts/convert_notebook.mjs
npm run build --prefix slidev
```

注意：第一条会重新生成 Slidev 和 Notebook，覆盖对这两份生成文件的直接编辑。若你希望分别维护，直接编辑源课件即可，不再运行第一条。`execute_notebook.py` 是为这份可信课件编写的顺序执行器，不可用于运行不可信 Notebook，也不能替代对 Jupyter 内核的验收。

## 教师试讲清单

1. 首页两种课件均能打开，中文字体清楚，投影比例合适。
2. Slidev 第 6 页和第 15 页的“下一步/重置”可用；Agent 页面明确标注教学模拟。
3. 第 11 页代码中将面积改为 4，输出包含 `100 N -> 25.0 MPa`；面积改为 0，显示 ValueError。
4. 第 18 页滑块从 2 改为 4，100 N 对应的值从 50 变为 25 MPa。
5. Notebook 转换版可左右翻页，N 可显示讲者备注；完整 Notebook 在空内核中顺序运行并保存图/CSV。
6. 没有真实 Agent 账号或现场网络不可用时，使用标注为模拟的流程动画和已执行输出；不把它介绍成实时 Agent 结果。
7. 若临时无法启动本机服务，直接打开 Notebook 转换 HTML 阅读内容与已执行结果；其程序/Agent 动画、滑块是本地页面，Python 按钮则需服务恢复后才能使用。
