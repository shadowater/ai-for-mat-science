# 第一次正式课：计算机基础、AI 与 Agent（120 分钟）

[返回课程入口](README.md) · [既有内容总纲](01_第一次课教学大纲.md)

本大纲安排 120 分钟的授课顺序、演示和课堂实践。

## 一、对象与学习目标

面向已学过高等数学和线性代数的材料、化学、化工研究生。编程知识从入门讲起。

本课结束时，学生应能：

1. 区分计算与存储、内存与硬盘，解释文件、程序和运行环境的基本关系。
2. 区分路径、文件格式、文本编码；看懂简单 JSON，并理解命令需要相应程序执行。
3. 在建模案例中指出人选择的内容与数据学习的内容，区分训练、使用和检验。
4. 说明语言模型生成内容、Harness 协调工具、工具实际执行之间的分工。
5. 用可用的 Agent 完成一次读取、计算和保存任务，核对实际输出。

全课主线：**计算机如何执行程序 → 文件如何表达信息 → 模型如何学习和生成 → Harness 如何连接操作 → 如何验证结果。**

## 二、课前准备与课堂边界

- 学生尽量提前装好计划使用的桌面端，或确认网页 Agent 可用。课上只确认入口与处理少量问题；正在处理安装问题的学生使用备用入口或与同伴共同观察，全班按计划继续。
- 教师提前启动本地小模型，检查最小二乘网页、Notebook 与 Harness；准备已有运行记录和输出文件，以便故障时展示并明确说明是先前结果。
- 将[课堂实践材料](内容/05_课堂实践与结果检查.md)中的课程样例放在学生容易找到的文件夹中，供学生直接使用。
- 演示集中使用一个命令行环境。学生用自然语言描述任务，由教师展示 Python 的执行过程。
- 第 4 章的教师演示和后续实践采用“读取数据—计算—保存—核验”的共同结构。若工具入口各异，教师说明具体实现的差别；学生使用已配置的课堂工具。

## 三、时间总表

| 时间 | 环节 | 主要方式 | 本段产出或检查 |
| --- | --- | --- | --- |
| 0—10 分钟 | Agent 入口确认 | 连接检查与一次短对话 | 每人或每组有可用入口 |
| 10—30 分钟 | 计算机、命令与运行环境 | 诊断回顾、单一命令和 Notebook 演示 | 能区分计算与存储，说明谁执行命令 |
| 30—45 分钟 | 文件、编码与信息格式 | 打开同一样例，观察与修改 | 能区分路径、编码、格式，看懂工具请求字段 |
| 45—90 分钟 | 第 4 章：从建模到语言模型与 Harness | 数学桥接、短动画、真实执行 | 能解释学习与执行的分工 |
| 90—110 分钟 | 学生实践与结果核验 | 独立或结对操作 | 一份实际输出与一次核对记录 |
| 110—120 分钟 | 结果核对、答疑与机动 | 核对学习目标与科研需求 | 留下输出文件和核对记录 |

合计 120 分钟。各段时间包含互动；遇到共性困难使用最后的机动时间，优先按文末方案压缩选讲内容。

## 四、逐段教学安排

### 0—10 分钟：确认 Agent 入口

确认 Agent 入口可用，发送一条简短消息，并查看模型回复。后续环节将介绍计算机执行、文件读取和模型生成的过程。

**材料：**[Agent 上手与模型服务](内容/01_Agent上手与模型服务.md)。

### 10—30 分钟：计算机执行程序的过程

#### 10—17 分钟：硬件分工与操作系统

展示处理器、内存和存储设备的作用：

- CPU 执行通用计算；GPU 适合许多可并行的运算，后面再连接矩阵计算。
- 内存保存正在使用的数据，硬盘用于持久保存；显存为 GPU 提供工作数据空间。
- 操作系统管理资源、文件和运行中的程序。应用软件依靠这些条件工作。

展示一台电脑的设备信息。用速度、容量与持久性的差异解释分工；硬件型号与采购留作兴趣拓展。

#### 17—24 分钟：图形界面、命令与 Python

只演示一次创建文件夹或改名的命令，说明文本命令是另一种表达操作的方式，需要由相应程序解析与执行。

在已有 Notebook 中修改半径并运行计算或绘图。说明 Python 代码由解释器及底层库等支持，最终由硬件执行；流程图展示本例实际经过的层次。

通过解释器的运行记录和实际输出确认代码已经执行。

#### 24—30 分钟：路径与运行环境

- 相对路径依赖当前工作目录；绝对路径明确文件所在位置。
- 环境变量提供程序运行时可读取的设置；PATH 是其中用于查找程序的目录列表。
- 用 `code .` 解释“找到程序”与“传入当前目录”是两件事，现场聚焦程序查找与目录参数。

下一段介绍程序如何解释文件中的数据。

**材料：**[计算机与运行环境](内容/02_计算机与运行环境.md)、[演示入口](演示/README.md)。

### 30—45 分钟：文件中的信息与格式

#### 30—35 分钟：文件、后缀与编码

文件后缀提供格式线索，文件内容由相应格式规则组织。文本编码规定字节与字符的对应关系；使用不匹配的编码读取文件可能出现乱码。

#### 35—41 分钟：CSV 与 JSON

复用现有样例，找到同一个样品字段：

- CSV 用行列表示表格，适合许多实验数据。
- JSON 用字段和值组织信息，值也可以包含列表或其他对象。

在 JSON 中找出字段名及其值。程序读取并处理 JSON 中的结构化数据。

#### 41—45 分钟：Markdown 与公式

打开一份 Markdown，观察正文、标题和公式预览。只修改一个参数或一处公式，说明源文本与显示结果的关系。

文本编码规定字节与字符的对应关系，嵌入向量表示模型学习到的数值特征。后续环节介绍模型如何利用输入进行预测和生成。

**材料：**[文件与科研信息](内容/03_文件与科研信息.md)。XML、Office 内部结构、完整 LaTeX 语法、PDF/OCR 与比例尺作为课后选读。

### 45—90 分钟：第 4 章——从熟悉的科研建模到 AI Agent

这一段负责解释开场使用的工具。参考[完整讨论稿](内容/04_AI与Agent的工作方式/新版教学大纲_讨论稿.md)与[50 分钟备课大纲](内容/04_AI与Agent的工作方式/50分钟必要内容大纲.md)，课堂按下列 45 分钟安排讲授。

#### 45—49 分钟：AI 与人工规则

- AI 是研究推理、学习、感知等智能任务的学科方向；具体系统通过程序实现。意识属于另一类研究问题，本课聚焦系统的任务与程序实现。
- 专家系统由人提供知识与规则，程序据此推理。用价态约束筛选合理结构；历史与图形题留作选读。
- “输入到输出的映射”是本课采用的数学视角；AI 与普通程序还需结合学习方式和任务背景理解。

#### 49—55 分钟：熟悉的模型与函数族

用 Arrhenius 方程唤起参数拟合经验，指出输入、输出、已选关系与待拟合参数。

$$k(T)=A\exp\left(-\frac{E_a}{RT}\right),\qquad \hat y=f_\theta(x).$$

人选择候选函数族，数据帮助确定具体函数。传统机器学习和神经网络都有这一共同点；科学模型还可用方程及求解条件等方式表达。

研究者选择 Arrhenius 方程形式，实验数据用于拟合参数。

#### 55—63 分钟：从最小二乘理解学习

以溶解度预测定义任务，再切换到三个虚构标定点展示直线拟合；在屏幕上标注“虚构标定数据”。

$$\hat y=ax+b,\qquad L=\sum_i(y_i-\hat y_i)^2.$$

手动改变一次参数，再播放梯度下降。解释残差、损失、训练与使用；直接解供教师备课时参考。

梯度由偏导数组成，梯度下降沿负梯度方向更新参数。训练后必须用独立留出的测试数据检验，关注外推范围。

更换训练数据后，模型形式可以保持，拟合参数可能改变。

#### 63—71 分钟：输入描述与神经网络

回到 ESOL：由分子描述符建立多元线性回归，重点观察描述符怎样进入模型。

用两层网络说明矩阵、偏置与非线性变换：

$$\hat y=W_2\sigma(W_1x+b_1)+b_2.$$

重点区分：关系表达能力与输入信息质量是两个分别检查的方面。深度学习可把中间表示的形成纳入学习，仍需人选择输入、结构和目标。反向传播只用一句“链式法则计算梯度”说明。

预测受温度影响的性质时，输入还需要包含温度等实验条件。

#### 71—79 分钟：语言模型的逐步生成

接回前面的文件编码，逐步说明：

> 字符 → token（模型处理的文本片段）→ 编号 → 嵌入向量 → 结合上下文计算 → 下一个 token 的概率分布 → 选择并继续生成。

嵌入表是训练参数；中间向量参与计算，最终概率分布用于选择下一个 token。课堂展示一次实际切分与短续写；向量算术、模型尺寸和完整训练过程留作选读。

上下文是本次调用提供的信息，普通对话更新本次上下文，训练过程更新模型权重。生成内容仍需核验。

#### 79—90 分钟：Harness 与真实执行

程序通过工具读取文件，并将读取结果提供给模型。

- Harness 是围绕模型组织上下文、协调工具与收集结果的程序层。
- 接回路径：工具返回读取结果后，才能确认文件内容已进入任务流程。
- 接回 JSON：请求用字段和值表达工具名称和参数。
- 接回命令与 Python：模型生成请求，工具及运行环境实际执行。

只运行一次读取半径、计算面积、保存报告的成功流程。在调用处暂停，指出请求、工具结果与实际文件。教师最小 Harness 展示受引导的工具流程；自主规划能力需要另行评估。

下一段使用课堂样例完成任务并检查输出。

**材料：**[第 4 章入口](内容/04_AI与Agent的工作方式.md)、[最小二乘](演示/最小二乘/README.md)、[本地语言模型](演示/本地语言模型/README.md)、[最小 Harness](演示/最小Harness/README.md)。

### 90—110 分钟：学生完成一次任务并核验

采用[既有课堂任务与检查要求](内容/05_课堂实践与结果检查.md)。围绕一个课堂任务，依次读取、处理、保存、检查。

- **90—93 分钟：**确认输入文件、目标输出和保存位置。学生在任务中明确这些条件。
- **93—103 分钟：**使用可用 Agent 完成任务；遇到错误时查看实际反馈、补充必要信息。教师重点处理共性问题。
- **103—108 分钟：**打开输出，核对至少一个原始字段或计算值；涉及计算时借助前面 Notebook 或计算器独立检查。
- **108—110 分钟：**展示输出文件的位置和核对结果。

最低完成证据是一份可打开的输出与一句核验说明。暂时缺少工具入口的学生与同伴共同检查，仍参与结果判断。

### 110—120 分钟：结果核对、答疑与机动

核对神经网络的人工设计与训练参数、独立测试数据上的表现，以及 Agent 的工具记录和输出文件。其余时间处理课堂共性问题，并记录后续科研任务。

## 五、前后概念如何衔接

| 前半段基础 | 第 4 章中的用途 |
| --- | --- |
| CPU、GPU | 理解模型计算的硬件基础，把 GPU 视为模型计算的硬件支持 |
| 编码、字符 | 与 token 和嵌入区分，理解不同表示层次 |
| JSON | 看懂工具名称与参数，由程序读取数据格式并执行操作 |
| 命令、解释器、环境 | 理解模型输出如何交给实际程序执行 |
| 路径、工作目录 | 理解文件访问需要具体位置和可用工具 |
| Markdown、保存文件 | 理解报告是实际产物，需要打开和核验 |

## 六、内容取舍与故障备用

**本次选读内容：**硬件采购与装机、多系统命令清单、Python 语法课、完整公式语法、K-Means/SVM/PCA、Uni-Mol 架构、反向传播推导、词向量类比、RAG、长期记忆和多 Agent。保留在原讲义中供查阅。

**发生超时时，按顺序压缩：**设备信息展示、Markdown 现场修改、梯度下降公式解释、神经网络公式展开、现场续写。保留实际执行演示、学生核验和最后三问。

**发生演示故障时：**展示既有实测请求、结果和报告，明确是先前运行记录。仍区分模型生成与工具执行；备用讲解控制在原定课时内。
