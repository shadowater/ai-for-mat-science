# 测量练习用的几何参考图

这里放两张**不是样品图**的教学夹具，供课堂卡 2、卡 3 和 Notebook 的 `SOURCE = "reference"` 使用：

| 文件 | 内容 |
| --- | --- |
| `03_particles.png` | 本课程生成的 256×320 像素模拟图。圆形、椭圆形区域经过高斯模糊，再加入固定随机种子的噪声。 |
| `03_particles_reference_mask.tif` | 与模拟图对应的几何参考标签。背景为 0，颗粒编号为 1、3、7、12、16、21、25、30、42；最后四个接触图像边缘。 |

它的作用是用已知几何检查读标签、面积、周长和边缘剔除：9 个颗粒、剔除 4 个、保留 5 个，编号 1 的面积为 1245 px²。课堂的样品图只有 `素材/` 中的三张 TiO₂ 电镜图。

重新生成（课程目录下）：

```bash
uv run python prepare_examples.py
```

参考图由本课程生成，随课程材料使用。
