# 神经网络的逐层计算：从加权求和到矩阵

[返回机器学习简介](2.2.2_机器学习简介.md#非线性激活与层的组合)

本节用一个 **3→2→2** 的教学网络，将每个神经元的计算逐项写出，再合并为向量和矩阵形式。三个输入依次进入两个隐藏单元，最后得到两个输出分数。以下参数用于演示计算过程。

## 1. 将输入排成一列

假设一个样品有三个输入数值，按固定顺序记为 $x_1,x_2,x_3$。例如，它们可以表示已经换算到适当尺度的三个实验条件。

$$x_1=1,\qquad x_2=2,\qquad x_3=3.$$

将三个数竖直排列，得到输入列向量：

$$\mathbf x=\begin{bmatrix}x_1\\x_2\\x_3\end{bmatrix}
=\begin{bmatrix}1\\2\\3\end{bmatrix}.$$

> **向量（Vector）**：按顺序排列的一组数。**列向量（Column Vector）**：将这些数排成一列的表示形式。

$\mathbf x$ 有 3 行、1 列，形状记为 $3\times1$。输入顺序决定每个位置代表的变量，训练与预测使用相同顺序。

## 2. 先写出每个隐藏单元的计算

两个隐藏单元分别使用一组权重和一个偏置：

$$a_1=w_{11}x_1+w_{12}x_2+w_{13}x_3+b_1,$$

$$a_2=w_{21}x_1+w_{22}x_2+w_{23}x_3+b_2.$$

权重下标的**第一个数字表示输出单元，第二个数字表示输入位置**。例如，$w_{23}$ 表示第 3 个输入到第 2 个隐藏单元的权重。

取以下参数：

| 输出单元 | 输入 1 的权重 | 输入 2 的权重 | 输入 3 的权重 | 偏置 |
| --- | ---: | ---: | ---: | ---: |
| 单元 1 | 1 | 0 | −1 | 1 |
| 单元 2 | 0 | 2 | 1 | −2 |

逐项代入：

$$a_1=1\times1+0\times2+(-1)\times3+1=-1,$$

$$a_2=0\times1+2\times2+1\times3-2=5.$$

因此，这一组加权求和得到两个数 $[-1,5]$。

## 3. 将两行公式合并为矩阵

把每个单元的权重作为一行，两行排在一起得到：

$$W_1=\begin{bmatrix}
w_{11}&w_{12}&w_{13}\\
w_{21}&w_{22}&w_{23}
\end{bmatrix}
=\begin{bmatrix}1&0&-1\\0&2&1\end{bmatrix}.$$

> **矩阵（Matrix）**：按行和列排列的数值表。矩阵的形状用“行数 × 列数”表示。

这里 $W_1$ 有 2 行、3 列：**两行对应两个输出单元，三列对应三个输入**。把两个偏置排成列向量：

$$\mathbf b_1=\begin{bmatrix}1\\-2\end{bmatrix}.$$

矩阵乘列向量时，矩阵的每一行分别与输入逐项相乘，再求和：

$$W_1\mathbf x=
\begin{bmatrix}1&0&-1\\0&2&1\end{bmatrix}
\begin{bmatrix}1\\2\\3\end{bmatrix}
=\begin{bmatrix}
1\times1+0\times2+(-1)\times3\\
0\times1+2\times2+1\times3
\end{bmatrix}
=\begin{bmatrix}-2\\7\end{bmatrix}.$$

再在对应位置加上偏置：

$$\mathbf a=W_1\mathbf x+\mathbf b_1
=\begin{bmatrix}-2\\7\end{bmatrix}
+\begin{bmatrix}1\\-2\end{bmatrix}
=\begin{bmatrix}-1\\5\end{bmatrix}.$$

这就是第 2 节两行标量公式的合写形式。形状关系为：

$$(2\times3)(3\times1)+(2\times1)=(2\times1).$$

矩阵列数与输入行数都为 3，因此三个输入可以按位置配对计算；结果的两行对应两个输出。

## 4. 对每个结果应用激活函数

接下来，对 $-1$ 和 $5$ 分别取“该数与 0 中的较大值”：

$$h_1=\max(0,-1)=0,\qquad h_2=\max(0,5)=5.$$

这一步使用 ReLU 激活函数。

> **ReLU（Rectified Linear Unit，修正线性单元）**：定义为 $\operatorname{ReLU}(z)=\max(0,z)$ 的激活函数。

将两个计算合写为：

$$\mathbf h=\operatorname{ReLU}(\mathbf a)
=\operatorname{ReLU}(W_1\mathbf x+\mathbf b_1)
=\begin{bmatrix}0\\5\end{bmatrix}.$$

这里的 ReLU **分别作用于每个分量**，输入和输出均为 $2\times1$ 列向量。

## 5. 输出层继续进行同样的加权计算

输出层接收 $h_1,h_2$，产生两个分数 $z_1,z_2$。设：

$$W_2=\begin{bmatrix}1&1\\-1&0.5\end{bmatrix},\qquad
\mathbf b_2=\begin{bmatrix}0\\1\end{bmatrix}.$$

逐项计算为：

$$z_1=1h_1+1h_2+0=5,$$

$$z_2=-1h_1+0.5h_2+1=3.5.$$

矩阵形式为：

$$\mathbf z=W_2\mathbf h+\mathbf b_2
=\begin{bmatrix}1&1\\-1&0.5\end{bmatrix}
\begin{bmatrix}0\\5\end{bmatrix}
+\begin{bmatrix}0\\1\end{bmatrix}
=\begin{bmatrix}5\\3.5\end{bmatrix}.$$

若用于两个类别的分类，两个数分别对应两类的分数。将其指数化后除以指数和，可以得到总和为 1 的输出：

$$p_1=\frac{e^5}{e^5+e^{3.5}}\approx0.8176,\qquad
p_2=\frac{e^{3.5}}{e^5+e^{3.5}}\approx0.1824.$$

这就是 Softmax 变换。第一个类别得分较高，模型将其作为预测类别。

## 6. 完整网络与参数数量

把两层连接起来，整个计算写成：

$$\mathbf z=W_2\operatorname{ReLU}(W_1\mathbf x+\mathbf b_1)+\mathbf b_2.$$

| 步骤 | 输入形状 | 参数形状 | 输出形状 | 本例输出 |
| --- | --- | --- | --- | --- |
| 第一层加权求和 | $3\times1$ | $W_1:2\times3$，$\mathbf b_1:2\times1$ | $2\times1$ | $[-1,5]^\mathsf T$ |
| ReLU | $2\times1$ | 固定激活函数 | $2\times1$ | $[0,5]^\mathsf T$ |
| 输出层加权求和 | $2\times1$ | $W_2:2\times2$，$\mathbf b_2:2\times1$ | $2\times1$ | $[5,3.5]^\mathsf T$ |
| Softmax | $2\times1$ | 固定变换 | $2\times1$ | 约 $[0.8176,0.1824]^\mathsf T$ |

上标 $\mathsf T$ 表示转置，这里将横排的数字表示为列向量。第一层有 $2\times3+2=8$ 个参数，输出层有 $2\times2+2=6$ 个参数，合计 **14 个可训练参数**。训练调整这些权重和偏置。

## 7. 推广到任意数量的输入与输出

对于 $d$ 个输入、$m$ 个输出，权重矩阵每一行对应一个输出，每一列对应一个输入：

$$W\in\mathbb R^{m\times d},\qquad
\mathbf x\in\mathbb R^{d\times1},\qquad
\mathbf b\in\mathbb R^{m\times1}.$$

符号 $\mathbb R$ 表示实数；例如 $\mathbb R^{m\times d}$ 表示具有 $m$ 行、$d$ 列实数的矩阵。

第 $j$ 个单元的标量公式为：

$$h_j=\phi\left(\sum_{i=1}^{d}w_{ji}x_i+b_j\right).$$

将全部 $m$ 个单元合写为：

$$\mathbf h=\phi(W\mathbf x+\mathbf b).$$

矩阵表达式把一层中各个单元的加权求和集中在一次运算中。程序中的 `@` 对应矩阵乘法，下面的代码复现本例：

```python
import numpy as np

x = np.array([[1.0], [2.0], [3.0]])
W1 = np.array([[1.0, 0.0, -1.0], [0.0, 2.0, 1.0]])
b1 = np.array([[1.0], [-2.0]])
h = np.maximum(0, W1 @ x + b1)

W2 = np.array([[1.0, 1.0], [-1.0, 0.5]])
b2 = np.array([[0.0], [1.0]])
z = W2 @ h + b2

# 减去最大分数可以提高指数运算的数值稳定性，概率保持相同。
exp_z = np.exp(z - z.max())
p = exp_z / exp_z.sum()
print(h)  # [[0.], [5.]]
print(z)  # [[5.], [3.5]]
print(p)  # 约 [[0.8176], [0.1824]]
```

本附件采用列向量约定。程序也常把一个批次的样本逐行排列；此时输入矩阵形状为“样本数 × 输入数”，一层的乘法写为 `X @ W.T + b`，偏置按输出位置加到每个样本上。阅读代码时，可先核对样本、输入和输出分别对应哪个维度。
