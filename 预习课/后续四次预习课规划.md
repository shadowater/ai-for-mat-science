# 预习课二至五与六次科研实践规划（教师讨论版）

更新：2026-10-21。本文用于教师讨论与取舍，不是学生讲义；具体任务与顺序仍可按学生需求调整。

## 一、以最新课程设想为准

正式第一课回顾预习内容、抽取同学提问、介绍 AI Agent 并完成安装配置。随后安排六次材料科研实践，由教师带领学生用 Agent 处理实际问题；最后一次暂沿用学生汇报安排。正式课结构已同步到[新版课程大纲](../ai_materials_course_outline.md)。

预习课二、三承担较宽的基础知识学习，使学生以后听到“像素、坐标、JSON、API、LaTeX”等概念时能理解例子并跟上操作。预习课四、五是两次 Python 基础选学，供希望进一步读懂、修改和核对程序的学生学习，不设为进入正式课的门槛。预习三明确加入 AI、机器学习、LLM 原理、Agent 与 agent harness，以及常见模型和 harness 的认识。Agent 的安装与首次实际操作安排在正式第一课，预习不依赖学生已经装好 Agent。

本文件维护当前预习内容的优先级及课堂衔接，后续按学生反馈调整。

每个基础概念安排一个小例子或动作，区分“认识并尝试过”和“能够独立完成”。多数动作自测即可，不要求每个知识点提交作业。预习二、三可先按每次约 2–3 小时课外学习量设计，拆成几个可分日完成的单元；Python 选学四、五先按每次约 2 小时设计，学生按需要选择。时间是试学预算，安装等待另计，需经零基础试学修正。

## 二、六次正式实践的暂定位置

| 实践 | 主题与主任务 | 建议产物 | 预习应铺的基础 |
|---|---|---|---|
| 1 | 图像与机器学习入门：手写数字分类作短引入，接触角测量作材料主案例 | 原图上叠加基线、轮廓、接触点与切线；输出左右接触角和处理参数 | 像素、灰度、坐标、分类与定位的差别、几何拟合、训练与使用模型的区别 |
| 2 | 曲线与谱图处理：NMR、红外、DSC 中选一个完整主例，另两个展示迁移与差别 | 原始与处理曲线、候选峰或转变区标注、结果表和处理记录 | 数值表与曲线图片、坐标单位、基线、噪声、阈值、平滑、峰与台阶 |
| 3 | 电镜颗粒或细胞识别：分开图中的每个对象，再统计 | 对象边界叠加图、编号、面积与尺寸分布、人工修订记录 | 比例尺、像素面积、分割、掩膜、对象编号、漏检和粘连 |
| 4 | 文献获取与解析：检索记录、获得可访问全文、解析和汇总 | 文献清单、PDF、解析结果、带原文位置的对照表和参考文献条目 | DOI、元数据、API、JSON、文本型与扫描型 PDF、OCR、来源追溯 |
| 5 | 论文整理与排版：使用期刊模板，插图、表、引用并编译 | 可编辑的 LaTeX 项目、参考文献库和 PDF | 源文件与输出、LaTeX 基础、图片格式、交叉引用、BibTeX 条目 |
| 6 | 学生需求专题 | 一个可重复使用的科研处理流程或轻量工具 | 复用前五次已学的文件、数据、程序与服务概念 |

第六次可选：把已有图像处理功能做成手机可打开的网页；批量处理学生仪器文件；文献数据整理；补充某一表征方法。模拟计算保留为后续候选，待目标体系、软件和计算资源明确后再决定。手机工具优先复用已验证的处理流程，是否需要 Android 应用由功能需要决定。

### 备课参考：案例细节留待后续完善

- 手写数字识别的输出是类别；接触角任务还需找基线、轮廓、接触点并计算几何关系。前者用来介绍机器学习，不直接作为后者的测量算法。
- 接触角可以从圆弧拟合的教学例子开始，但需说明形状假设；真实液滴不总能由一个圆充分描述。要保留轮廓和拟合叠加图，便于检查。圆拟合及其局限见 [KRÜSS 说明](https://images.kruss-scientific.com/en/know-how/glossary/circle-method)。
- NMR 的“找峰并标注位置”“积分与多重峰处理”“把信号归属到分子中的原子”是不同层次。先确定输入是原始仪器数据、处理后的数值谱，还是谱图图片，再确定课堂任务。完整结构归属作为进阶目标；专业软件也区分找峰与归属步骤，见 [Bruker NMRtist](https://www.bruker.com/en/products-and-solutions/mr/nmr-software/nmrtist.html)。该工具面向蛋白 NMR，仅用于说明步骤差异，不据此推荐给小分子案例。
- 红外的吸光度与透过率纵轴需要区分，峰的方向和处理规则随数据表达而变；候选峰位置与化学归属分别核对。
- DSC 需要区分峰形事件与玻璃化转变的台阶，并明确采用起始点、中点还是峰温。NETZSCH 的[实例](https://analyzing-testing.netzsch.com/_Resources/Persistent/6/1/b/d/61bd0d4c4bcb1be82711830a16525d387420f9ac/AN%20302_TM-DSC%20%E2%80%93%20The%20Method%20of%20Choice%20for%20Determination%20of%20the%20Glass%20Transition.pdf)展示了玻璃化转变中点与峰温、焓值的分别评估。一节课先做一个完整案例，再讨论方法迁移。
- 颗粒与细胞识别可以共享“分割—测量—统计”的流程，但模型对新图像的适用性要用样例检验。[Uni-AIMS](https://bohrium.dp.tech/apps/uni-aims)面向电镜图像；[Cellpose](https://cellpose.readthedocs.io/en/latest/gui.html)支持模型分割、人工标注和修订。软件选择待真实图像试跑后确定。
- 图书馆是否提供可调用接口、认证和全文获取方式，需要学校的具体文档。可先用 [Crossref API](https://www.crossref.org/documentation/retrieve-metadata/rest-api)演示文献元数据检索；查到记录或全文链接，不表示已经取得可下载的全文。[MinerU](https://github.com/opendatalab/MinerU)与 [Uni-Parser](https://uniparser.dp.tech/api)可作为解析环节的候选，结果中的数值、公式和来源位置需回到 PDF 核对。

## 三、预习课二：文件、数据和科研文档怎样表示

建议分为四个短单元。JSON、PDF 与 LaTeX 纳入共同学习内容；掌握深度以读懂简单例子、尝试改动为准。

| 单元 | 基础知识与直白解释 | 具体动作 | 对应正式实践 |
|---|---|---|---|
| 1. 文件与位置 | 文件名、后缀、格式、打开方式；文件夹层级；绝对路径与相对路径；改后缀不等于转换格式 | 解压资料包，显示后缀，找到文件；移动整个包后检查相对链接；保留原始数据和结果两个目录 | 所有实践 |
| 2. 文本、表格与结构化信息 | 纯文本；Markdown；CSV 是按行列组织的表格文本；JSON 用名称和值描述信息，也可放列表与层次 | 用 VS Code 和表格软件打开同一 CSV；在简单 JSON 中修改样品编号和一个参数；观察数字与文字的区别 | 曲线处理、API 返回值、批量汇总 |
| 3. 数据表与曲线 | 一列的含义与单位；缺失值与零；样品编号；测试条件；横纵轴、轴方向与范围；原始数值、处理数据和曲线图片的区别 | 对照同一曲线的 CSV 与 PNG，找到一个数值点；指出仅看图片时丢失的精确数据；读懂一份包含单位和测试条件的说明 | NMR、红外、DSC及后续其他测试 |
| 4. 文献与论文源文件 | PDF 可包含文本或扫描图；OCR 是从图中识别文字；DOI 是文献标识；元数据是题名、作者等描述信息；LaTeX 源文件经排版程序生成 PDF；`.bib` 保存参考文献记录 | 比较两份 PDF 能否选中文字；在给定 LaTeX 模板中改标题、插入一个引用并重新生成 PDF；找到引用对应的 `.bib` 条目 | 文献解析、论文排版 |

### 第二次的内容深度

- Markdown 延续第一次：标题、列表、链接、图片和代码块；表格能读写简单例子即可。
- CSV 保留表头、分隔符、数字与文本、空值、单位；CSV 引号处理交给软件，学生知道含逗号的字段不能随意切分即可。
- JSON 认识名称和值、列表、数字、文本、真假、`null`，可修改一个简单例子。复杂嵌套与格式验证规则留作选读。
- 曲线基础借用学生熟悉的专业图，解释数据怎样表达。基线是信号的背景水平，噪声是测量中的波动；只先观察，不提前推导滤波算法。
- LaTeX 认识 `\section{}`、简单公式、`\includegraphics{}`、`\label{}`/`\ref{}` 和 `\cite{}`，知道花括号用于包住内容。给完整可运行例子，不要求从零搭模板。文献条目与引用关系可参考 [Overleaf 示例](https://www.overleaf.com/learn/latex/Bibtex_bibliography_styles)。排版环境统一提供或使用浏览器入口，本次不要求安装完整本地 LaTeX。
- 简单了解 UTF-8、乱码、中英文标点、XLSX 导出 CSV 的信息变化；遇到例子时解释。

建议资料包包含：一份模拟曲线 CSV、同一曲线图、描述实验条件的 JSON、Markdown 说明、可合法分发的文本型与扫描型 PDF 示例、最小 LaTeX 项目和 `.bib`。这些由教师准备，不要求学生自己搜集整套材料。

建议自测：能说出每个文件存什么、用什么打开、怎样关联；能完成一次 JSON 参数修改和一次 LaTeX 编译。无需逐项写报告。

## 四、预习课三：图像、运行环境与 AI 基础

图片知识与 AI 基础都作为共同学习内容。建议分成“图像与颜色”“软件、网络与环境”“AI、模型与 Agent”三个短单元，可分日完成；每个单元通过例子建立概念。

| 单元 | 基础知识与直白解释 | 具体动作 | 对应正式实践 |
|---|---|---|---|
| 1. 图像是怎样存起来的 | 像素是一格颜色；灰度是亮暗数值；RGB 用三组数表示颜色；透明度；宽高与坐标；二维数表和多通道图像的直观关系 | 放大手写数字或液滴小图；在小网格中读取一个像素值；用图像查看器找到一点的坐标 | 手写数字、接触角、细胞与颗粒 |
| 2. 科研图像的尺度与输出 | 位图与矢量图；PNG/JPEG/TIFF/SVG/PDF；有损与无损；像素尺寸、排版尺寸与 DPI/PPI；比例尺；RGB/HEX 配色 | 比较同图的 PNG 与 SVG；按比例尺换算长度；给定颜色代码改变标注；区分原始图与加了标记的展示图 | 接触角、颗粒尺寸、论文插图 |
| 3. 图像任务的几种输出 | 分类是给整图一个类别；定位是找位置；分割是划出像素区域；掩膜是记录哪些像素属于目标的图；实例编号区分每个对象 | 看同一张颗粒图的类别、框、轮廓和编号图；指出漏掉或粘连的对象；比较原图和结果叠加图 | 三类图像实践的共同基础 |
| 4. 软件、网络和服务 | 下载、安装、启动、运行；编辑器与解释器；本地与远程；网页与后台服务；API 是程序向另一程序提交请求的接口；请求、响应、参数和身份凭据 | 画出“手机上传图片→服务处理→返回图片和数值”的流程；读一份现成 JSON 响应；观察本地副本修改是否影响已上传副本 | 文献接口、解析服务、手机网页 |
| 5. AI、机器学习与 LLM | AI、从数据学习、神经网络；训练与预测；token、上下文、参数、注意力与逐步生成；多模态输入 | 比较手写数字分类与文本生成例子；指出输入、训练样例、模型输出和检查方式 | 理解图像任务与模型能力 |
| 6. Agent、harness 与常见工具 | Agent 围绕目标调用工具；harness 组织模型调用、上下文、工具执行、权限与记录；模型系列与软件入口各有作用 | 看短演示，指出模型建议、工具执行和输出文件；把给出的名称分为模型系列与 Agent 工具 | 正式第一课安装 Agent、随后六次实践 |

### 第三次的内容深度

- RGB/HEX 要能辨认、复制和修改颜色值，不练十六进制换算。
- 图片坐标与数学坐标的方向可能不同，应按课程工具实例说明。缩放、裁剪以后需重新核对坐标与标定信息。
- 示例换算：比例尺 100 像素对应 10 μm，则 30 像素对应 3 μm；面积需使用长度比例的平方。矩形裁剪框与真实目标区域分别展示。
- 分类、分割与拟合通过不同输出图认识，不要求写算法。手写数字可作直观入口，液滴和颗粒图片负责连接科研任务。
- 网络部分认识网址、服务器、上传下载、请求响应、任务等待与失败即可；HTTP 细节、容器网络和部署原理选读。
- API 概念用教师准备的请求与响应示例解释，不要求此时申请服务账号、付费或保管真实 API Key。
- 运行环境在本次认识用途、文件位置和操作入口；进入并运行 Python 的练习安排在选学四、五。正式第一课统一完成或复核环境与 Agent 配置，不以完成 Python 选学为前提。

建议资料包包含：小尺寸手写数字图、液滴图、带比例尺的颗粒或细胞图、PNG/SVG 对照图、简短 API 请求与 JSON 响应例子、软件环境导读。图像需可分发且注明来源；掩膜等概念可以用教师制作的示意例子说明。

建议自测：能指出图像尺寸和目标位置，完成一个比例尺换算；能解释请求发到哪里、返回什么、文件保存在哪里。每个单元安排短操作，保留一个综合自测即可。

### AI、LLM 与 harness 的概念单元

| 主题 | 认识范围 | 具体例子或动作 |
|---|---|---|
| AI | 让计算机完成识别、预测、生成和决策等任务的技术领域；机器学习是其中一类方法 | 比较按公式算应力、识别手写数字、生成文献摘要三种任务 |
| 机器学习 | 用数据调整模型；数据、标签、训练、预测、测试；分类与回归；神经网络的直观认识 | 用带数字标签的图片说明训练，再用未见图片说明测试 |
| LLM 基本原理 | token 是模型处理的文本片段；训练会调整模型参数；模型结合上下文逐步生成；注意力机制关联不同位置的信息；认识预训练和后续训练 | 观察同一问题在提供和未提供文献片段时的回答；讨论本次上下文与训练中学到的信息有何区别 |
| 使用限制 | 上下文容量、错误生成、信息遗漏；流畅回答仍需检查；提供更多上下文不等于立即重新训练模型 | 找出一个与原始表格不一致的摘要数字 |
| 多模态与专用模型 | 多模态模型可接收文本、图像等信息；不同模型擅长不同输出 | 比较“描述图像内容”和“返回每个颗粒的轮廓” |
| Agent | 围绕任务选择并使用工具，根据结果继续行动 | 阅读“找文件→写处理脚本→运行→检查输出”的简短记录 |
| Agent harness | 围绕模型组织任务的软件支撑：准备上下文、提供工具、执行调用、管理权限、记录结果和继续循环 | 指出模型提出运行请求后，由哪个程序实际执行；比较只提供文字与允许读文件时能完成的任务 |
| 模型与产品 | 模型系列、聊天产品、Agent 工具、编辑器和运行环境的区别；这些不是一条简单的上下级分类链 | 对照名称卡片，说明每一项在课程中负责什么 |

LLM 原理以直觉和例子为主，不要求数学推导或背诵网络结构。可从 [Google 的 LLM 入门](https://developers.google.com/machine-learning/crash-course/llm)选取教师参考内容。Harness 的功能划分参考 [VS Code 官方概念说明](https://code.visualstudio.com/docs/agents/concepts/agent-harnesses)，不同产品实现存在差异。

### 常见模型与 harness 的认识范围

| 类别 | 课程可介绍的代表 | 需要理解的区别 |
|---|---|---|
| 模型系列 | [GPT](https://developers.openai.com/api/docs/models)、[Claude](https://platform.claude.com/docs/en/models/overview)、[Gemini](https://ai.google.dev/gemini-api/docs/models)、[Qwen](https://qwenlm.github.io/)、[DeepSeek](https://api-docs.deepseek.com/) | 文本、图像、代码和工具调用能力各有差异；访问方式、速度和费用由具体型号及服务决定 |
| Agent 工具与 harness | [Codex CLI](https://learn.chatgpt.com/docs/codex/cli)、[Claude Code](https://code.claude.com/docs/en/overview)、[Gemini CLI](https://geminicli.com/docs/)、[VS Code 中的 Copilot 等 harness](https://code.visualstudio.com/docs/agents/concepts/agent-harnesses) | 负责把模型能力接到文件、终端和任务流程；选择模型与选择 harness 是不同操作 |
| 工作入口和执行环境 | VS Code、浏览器中的 Jupyter、终端、Docker 容器 | 分别负责编辑、交互或运行程序；不因安装了这些软件就自动具有模型能力 |

以上用于认识工具生态，不要求学生安装全部产品，也不承诺所有模型与 harness 可以任意组合。具体版本、兼容性、账号和课堂主工具开课前核对。名称中出现 Codex 等词时，按上下文说明指模型还是 CLI 等产品。

## 五、预习课四、五：Python 基础选学

| 次数 | 内容 | 示例与动作 | 留到以后 |
|---|---|---|---|
| 四（选学）：数据和执行流程 | 最少终端操作；变量、数字与文字、列表和字典；比较与条件；遍历与循环；缩进和常见报错 | 用样品记录或几个人工可核对的数据点，预测结果、运行、改变阈值或新增一条数据、修复一次错误。练习取出一个字段、一行或一个坐标 | 复杂推导式、递归、完整算法课 |
| 五（选学）：函数、文件和结果 | 函数的参数与返回；导入模块；读 CSV 或 JSON；写出新文件；使用现成绘图例子；区分原始数据与处理结果 | 教师提供完整骨架，学生修改处理参数、输出列或图中标签，保存曲线及结果表，并核对一行数据。了解一个函数调用对应哪个处理步骤 | 类可用简短附例认识；复杂面向对象、框架搭建和独立编写仪器解析器留作选学 |

两次均为选学，不另设全班必交作业，也不作为正式课入场检查。未选学者在正式课使用给定程序和 Agent 完成实践，按任务补充必要解释。

示例可复用预习二、三中的曲线、实验条件或图像坐标，避免把所有基础限定在拉伸一个任务上。提供模拟数据及可人工核对的小样本。第四次聚焦程序结构，第五次体验完整处理过程。

允许用已经能访问的对话式 AI 搜索解释或排错；学生需要指出自己改了哪里、输出怎样变化，并做一次独立核对。练习不依赖 Agent 已完成安装。

## 六、Docker 与统一环境：大纲层面的方案

Docker 的课程用途是把 Linux 工具、Python、Jupyter 和相关依赖打包成可重复启动的环境。镜像是准备好的环境模板，容器是启动后运行的实例；映射课程文件夹后，容器中的程序可以访问其中的文件。学生先知道这些名称对应什么操作。

“像一台可用的 Linux 工作环境”可以作操作层面的理解，但容器不是一套完整独立的操作系统。Linux 容器共享所在 Linux 环境的内核；Docker Desktop 在 Windows/macOS 上通常通过 Linux 虚拟环境提供支持。依据见 [Docker 容器概念](https://docs.docker.com/get-started/docker-concepts/the-basics/what-is-a-container/)与 [Docker Desktop 运行方式](https://docs.docker.com/desktop/features/vmm/)。

| 方案 | 课程入口 | 统一管理方式 | 本轮需要确定的条件 |
|---|---|---|---|
| 本地 Docker | 学生电脑运行课程容器，浏览器访问其中的 Jupyter，终端进入容器运行命令或 Agent CLI | 教师提供镜像、启动配置和 Windows/macOS 视频；只映射指定课程文件夹 | 学生设备、磁盘与内存、处理器架构、安装支持和网络条件 |
| 服务器环境 | 通过统一地址登录，每人进入自己的环境和工作目录 | 教师维护服务器；可评估 JupyterHub 管理个人服务与登录 | 可用机器、并发人数、持续维护、账号与文件权限、保存和导出 |

可以先试装本地方案，并保留服务器方案供比较；当前尚未确定最终部署。选学学生可提前使用课程环境，正式第一课为全班复核环境和完成 Agent 配置。

三个概念需讲清：

1. **文件夹映射**：本地课程文件夹与容器路径相连，程序的修改可直接反映到本地文件；数据保存位置要明确。参见 [Docker bind mounts](https://docs.docker.com/engine/storage/bind-mounts/)。
2. **端口与访问入口**：浏览器通过地址和端口找到容器中的 Jupyter 服务。本地使用可以只向本机开放；服务器统一入口还需登录和每人服务管理。端口本身不提供用户隔离。参见 [Docker 端口映射](https://docs.docker.com/engine/network/port-publishing/)与 [JupyterHub](https://jupyterhub.readthedocs.io/en/stable/)。
3. **运行位置**：容器里的 Agent CLI、Python 和 Notebook 可以在本机执行，模型请求仍可能发往云端。统一镜像可以减少依赖配置差异，但服务账号、联网和设备差异仍需确认。

本轮只记录环境用途和候选路线，具体镜像、版本、命令、认证与部署视频后续制作。

## 七、材料表征自动化候选库

以下是供选题的方向，不是承诺全部开课。仪器厂商的目录可用于核对方法范围：[Thermo Fisher 表征方法](https://www.thermofisher.com/in/en/home/products-and-services/promotions/industrial/discover-solve-assure.html)、[NETZSCH 热分析方法](https://analyzing-testing.netzsch.com/en-US/services/contract-testing/methods)、[Malvern Panalytical 颗粒表征概览](https://www.malvernpanalytical.com/en/learn/knowledge-center/whitepapers/wp120620basicguidepartchar)。下表的课堂自动化任务是课程设计建议。

| 数据类型 | 测试候选 | 可考虑的自动化任务 |
|---|---|---|
| 图像 | 接触角、SEM/TEM 电镜、光学显微、细胞图像 | 轮廓与区域识别、对象计数、尺寸统计、叠加标注 |
| 光谱与衍射 | NMR、FTIR 红外、Raman 拉曼、XRD 衍射、XPS 光电子能谱 | 文件批量整理、绘图、基线处理、候选峰标记；需要专业约束的归属与拟合单独安排 |
| 热分析 | DSC、TGA 热重、DMA 动态力学分析 | 温度和信号列规范化、关键区间标注、按约定方法计算指标、重复实验比较 |
| 力学与流变 | 拉伸、压缩、流变 | 单位换算、曲线对齐、指定区间拟合、重复实验汇总 |
| 电化学 | 循环伏安、充放电、阻抗 | 批量读文件、按循环或样品汇总、曲线绘制；具体性能指标和拟合方法由案例确定 |

优先挑选输入可取得、规则可说清、结果可人工抽查、三小时能形成产物的任务。曲线课先统一处理与检查的基本步骤，再保留各测试的专门规则。通用找峰工具可参考 [SciPy find_peaks](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.find_peaks.html)，其输出是满足数值条件的局部峰，不自动完成化学或材料学解释。

## 八、教学准备与后续取舍

- 预习二开始让学生思考自己的科研任务；预习三结束前收集原课程通知要求的同一份构想。内容包括重复操作、输入样例或文件类型、期望输出、人工检查方式，以及是否可用于课堂讨论。学生可提供模拟或脱敏样例，不要求提前完成处理。
- 第一堂正式课可以抽问：CSV 与曲线截图有何不同；像素长度怎样换成实际长度；PDF 解析后如何核对；API 返回的 JSON 存什么；`.tex`、`.bib` 和 PDF 怎样关联。再通过例子回顾 AI、机器学习、LLM 和 harness；随后安装 Agent 并完成一次简单操作。Python 语法不作为全班抽问门槛。
- 首先确定 Python 入口与支持方式；随后验证各候选工具能否处理真实样例。学校图书馆接口的可用性需要具体学校与接口文档，不能由通用文献 API 推定。
- 学生材料仍按独立预习课文件夹制作：先审定英文，再完整翻译中文；本地阅读与图片放在该课文件夹，保留相对链接、作者、版本、许可和改动说明。
- 本文件为教师规划，后续在本仓库维护。待内容 review 后，再编写各课双语学生导读和分发包。
