# Sources and use / 来源与使用

The files in this folder were created for preparation class 2 in 2026: two short Markdown notes, a schematic SVG, a CSV, a JSON file, and two one-page PDF examples. `M-02` is fictional. The PDF examples contain the same key phrase; one stores page text, while the other embeds a raster image without a text layer. They are not copies of research papers.

本文件夹的两份 Markdown 笔记、SVG 示意图、CSV、JSON 和两份单页 PDF 均为 2026 年预习课二自编样例。`M-02` 是虚构样品。两份 PDF 含有相同的关键短语：一份存有页面文字，另一份嵌入位图，没有文字层。它们不是科研论文的副本。

The bibliographic record in `paper-record.en.md` and `paper-record.zh.md` names a real publication and links to its DOI and original publisher page. It includes only identifying metadata. The external teaching references in the guides are links to official original pages; no third-party reading, image, or paper PDF is redistributed here.

`paper-record.en.md` 和 `paper-record.zh.md` 记录真实文献的题名、作者、年份、DOI 与出版方原始页面，仅含识别文献所需的元数据。导读中的外部教学参考资料均链接到官方原始页面；这里没有重新分发第三方讲义、图片或论文 PDF。
