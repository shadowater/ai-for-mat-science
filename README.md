# AI Agent 材料科研实践 · 课程材料

本仓库收录材料、化工、高分子等方向研究生的课程材料。课程面向没有计算机基础的学生，从具体科研任务出发，练习找到输入、处理数据、核对结果，并说明可复用的工作流程。

| 预习课大纲 | 二、三为文件、图像与 AI 的共同基础；四、五为 Python 选学 | [预习课规划](预习课/预习课规划.md) |

| 后续预习课学生材料 | 按大纲逐步制作 | 完成后加入 `预习课/` |

预习课一的两份导读内容对应：[English](预习课/预习课一/README.md) · [中文](预习课/预习课一/README.zh.md)。本地阅读材料所需的图片随文件夹一同提供；视频和原始来源使用在线链接。

第一课教学包含模拟拉伸数据、Notebook、课件和课堂任务模板。它是早期备课与试讲材料，待按当前正式课大纲取舍；学生使用前请以教师当次通知为准。

## 后续维护

正式课大纲、预习课大纲和问卷以本仓库版本为准。大纲仍可按学生需求调整；教师规划与学生导读分别标注。学生材料先审定英文，再同步完整中文版本。问卷尚未创建在线表单或发送；学生填写结果不提交到公开仓库。
