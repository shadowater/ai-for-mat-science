# AI Agent 材料科研实践 · 课程材料

本仓库收录材料、化工、高分子等方向研究生的课程材料。课程面向没有计算机基础的学生，从具体科研任务出发，练习找到输入、处理数据、核对结果，并说明可复用的工作流程。

第一课以一个教学大纲和一组中文讲义维护，当前范围为 1.1—1.4.4，包含 Agent 上手、计算机基础、科研文件、人工规则、机器学习与神经网络。语言模型、Harness、工具调用和原综合实践等后续材料保留在第一课归档目录。

## 后续维护

正式课大纲、预习课大纲和问卷以本仓库版本为准。大纲仍可按学生需求调整；教师规划与学生导读分别标注。后续备课按当前约定仅维护中文；已有英文材料保留，不再要求同步更新。问卷尚未创建在线表单或发送；学生填写结果不提交到公开仓库。
